    Semua Transaksi

    Menu Agent Tele terkunci

    Menu ini bisa mengirim pesan atas nama akun Telegram tim, jadi memakai password tersendiri (berbeda dengan password dashboard).

    Status Agent

    Panduan memakai bot Telegram (tanpa my.telegram.org)
    1. Buka Telegram, cari @BotFather, kirim /newbot, beri nama (mis. Dashsan Sales Bot) dan username yang berakhiran bot.
    2. BotFather memberi token (format 123456:ABC...). Simpan di Vercel → project dashsan → Settings → Environment Variables dengan nama TELEGRAM_BOT_TOKEN, lalu Redeploy.
    3. Masukkan bot ke tiap grup CS (Tambah anggota → cari username bot). Agar bisa mengirim pesan, bot cukup jadi anggota biasa.
    4. Setelah bot masuk, kirim satu pesan apa saja di grup tersebut, lalu klik Deteksi grup baru di bawah (dalam 24 jam).
    5. Pilih platform untuk tiap grup, centang Aktif, klik Simpan pengaturan. Coba dulu lewat Pratinjau & Kirim Manual sebelum menyalakan jadwal.
    6. Komunitas manual: di Telegram → Settings → Chat Folders → Create Folder → masukkan semua grup CS → Share Folder untuk mendapat satu link gabung.

    Akun Telegram

    Terhubung sebagai

    Untuk memutus dari sisi Telegram: Settings → Devices → sesi Dashsan. Atau klik tombol di bawah.

    1. Login ke my.telegram.org memakai nomor akun khusus → API development tools → buat aplikasi (nama bebas, mis. Dashsan). Salin api_id dan api_hash.
    2. Isi di bawah, klik Simpan API, lalu Scan QR.
    3. Di HP akun khusus: Telegram → Settings → Devices → Link Desktop Device → arahkan kamera ke QR.

    Menunggu scan… QR diperbarui otomatis.

    Komunitas

    1 grup per platform + 1 link untuk bergabung ke semuanya

    Lewat bot — 1 klik per platform

    1. Klik tombol platform di bawah (paling mudah dari HP yang login akun khusus). Telegram terbuka dan meminta memilih grup: pilih buat grup baru atau grup yang sudah ada, lalu setujui bot sebagai admin.
    2. Kembali ke halaman ini — Dashsan mendeteksi otomatis, memberi nama grup sesuai platform (mis. JadiASN), membuat link undangan, dan mengaktifkan grup.
    3. Setelah semua grup jadi, satukan jadi komunitas: Telegram → Settings → Chat Folders → Create Folder (nama: Dashsan CS) → Add Chats → pilih semua grup CS → simpan → Share Folder → salin link. (Bagian ini wajib manual: bot tidak bisa membuat folder.)

    Lewat akun Telegram — otomatis penuh

    Butuh akun Telegram yang terhubung (scan QR). Grup dibuat satu per satu dengan jeda ±8 detik; grup yang sudah ada tidak dibuat ulang.
